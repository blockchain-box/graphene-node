      Connect a server

      On the other server, choose Share this server in its launcher. Paste its private Grph P2P connection link here.

      The encrypted Grph tunnel connects directly to the peer. Keep its launcher running. Access stays in memory; reconnect after restarting this launcher.

      Connecting a server without a desktop

      On the server, run:

      GRAPHENE_P2P_SHARE=1 npm run join

      Copy the private grph:// connection link printed in that terminal. Both hosts need UDP access to the configured DHT network. There is no SSH or direct HTTP fallback.

      Share this server

      Only share this private link with a computer you trust to manage this host. It includes an access code, so anyone holding it can operate this launcher.
